# BAR BRAWL — 프로토타입 v0.1

1920년대 재즈바, 무대 위 연주자 둘이 **스윙 재즈로 붙는** 리듬 배틀.
프나펑식 콜 앤 리스폰스 구조 위에, 체력바를 **스포트라이트 뺏기**로 바꾼 버전.

## 실행 방법
1. **Godot 4.2 이상**에서 `project.godot` 열기 (열면 wav 자동 임포트됨)
2. F5(실행). 3-2-1 카운트인 후 시작

## 조작
- **이동/받아치기**: 방향키 ← ↓ ↑ → (또는 두 손 대체키 `D F J K`)
- **다시하기**: Enter (결과 화면에서)
- **싱크 조정**: `[` `]` — 소리가 밀리면 좌우로 미세조정 (offset 표시됨)

## 이번 버전에 들어간 것
- **스포트라이트 뺏기 (차별점 1)**: 체력바 없음. 잘 받아치면 스포트라이트가 내 쪽으로 기울고, 놓치면 상대 쪽으로. 위 줄다리기 바 + 양옆 연주자 밝기로 보임. 한쪽으로 꽉 차면 즉시 승/패, 아니면 곡 끝 시점 판정.
- **콜 앤 리스폰스**: 상대가 한 소절 자동 연주(콜) → 다음 소절 내가 받아침(리스폰스). 마지막엔 2박씩 빠르게 주고받는 트레이딩 구간.
- **노트 4종**:
  - `TAP` 짧게 한 번
  - `HOLD` 롱노트 (누르고 꼬리 끝까지 유지 → 보너스)
  - `RAPID` 연타 (`x5` 표시된 원 안에서 그 레인 5번 이상 두들김)
  - `SLUR` 이어치기 (연결선으로 묶인 노트를 순서대로)
- **연주 톤**: 받아칠 때마다 실제 재즈 톤이 울림 = "내가 솔로를 친다"
- **스윙 백킹**: 워킹 베이스 + 스윙 라이드/브러시, 132 BPM 트리플렛 스윙 (전부 절차적 생성)
- 판정: PERFECT / GOOD / MISS, 콤보, 점수

## 아직 안 넣은 것 (다음 이터레이션)
- 스테이지별 악기 교체 (지금은 STAGE 1 · PIANO 고정). 곡·톤 세트만 바꾸면 트럼펫/바이올린 스테이지로 확장.
- 상대 캐릭터 여러 명 (프나펑처럼 스테이지 = 상대 교체)
- SLUR/RAPID 판정 정교화, hold 중간 놓침 페널티
- 채보를 외부 파일(json/txt)로 분리 → 채보 찍기 편해짐
- 진짜 재즈 음원 교체 (지금 백킹은 합성음, 자리표시용)

## 파일 구조
```
project.godot     설정 (입력맵은 코드에서 등록)
Main.tscn         루트 씬
Main.gd           전체 로직 (지휘/노트/판정/스포트라이트/렌더)
audio/            backing.wav, tone0-5.wav, miss.wav (절차적 생성)
```

## 튜닝 포인트 (Main.gd 상단 상수)
- `SCROLL` 노트 내려오는 속도
- `W_PERFECT / W_GOOD / W_MISS` 판정 관용폭
- `S_*` 스포트라이트 증감량 (난이도 밸런스)
- `_build_chart()` 채보 — 여기서 노트 배치 수정
